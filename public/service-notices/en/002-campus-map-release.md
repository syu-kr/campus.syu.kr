## New services

### Campus map

- **Information on more than 40 buildings**: Find all major buildings on campus
- **Search**: Quickly search by building or facility name
- **Facility information**: See facilities on each floor, including the library, cafés, and convenience stores
- **Responsive design**: Optimized for mobile and desktop

You can open it directly from the "Campus Map" menu on the home page!

### Real-time shuttle locations

The real-time shuttle location feature is complete!

- Real-time bus locations on Kakao Maps
- Different marker colors for vehicle status, routes, and destinations
- Search for a bus or click it for details
- A responsive interface optimized for mobile

Try it now through "Shuttle" → "Real-time Bus Locations" in the campus menu!
