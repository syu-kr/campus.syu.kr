Hello from SYU CAMPUS.

We have updated the **Timetable Builder** to make comparing several timetables easier as you prepare for course registration.

We improved features and page layouts around the actual flow of finding courses, comparing timetables, saving, and sharing.

---

## Updated features

### More detailed course search and filters

- Search by course name, professor, or course code, as well as **area, notes, department, college, location, and class time**.
- Select several days to find courses meeting on at least one of those days.
- Specify starting and ending periods to find courses overlapping that range.
- When a query matches an area, note, or another field, the result also shows which information matched.

### An easier-to-read weekly timetable

- The weekly timetable initially shows **Monday through Friday, periods 1 through 9**.
- If a selected course has a later period, the timetable expands in sequence through the last period needed.
- Selecting a Saturday or Sunday course automatically adds the necessary weekend day.
- On desktop, the weekly timetable and Add Course panel have matching heights, and the page makes better use of wide screens.

### Select and compare several timetables

- On desktop, press **Multiple Timetables** to compare between 2 and 4 timetables.
- Select timetables 1–4 directly on each course to add it to the combinations you want.
- Timetables can be duplicated and deleted. Scrolling one timetable vertically moves the others to the same position.
- Mobile and tablet show one selected timetable while keeping the other saved timetables intact.

### Saving and sharing

- Timetables you create are automatically saved in the current browser for 30 days.
- Create a link to share a single timetable or a set of timetables.
- Use **Save Image** to download the current timetable as a PNG image. When using multiple timetables, up to 4 are saved together in one image.

Try these features on the [Timetable Builder page](/academic/timetable).

## Tell us what could be improved

If you encounter any of the following while using the timetable, please let us know through **Contact the site** at the bottom of the page:

- Course information that cannot be found or incorrect class times
- Layouts that are difficult to use at particular screen sizes
- Problems selecting, sharing, or saving timetable images
- Small features or usability improvements you would like us to add

We will review your reports and suggestions and use them to improve the data and service.

If the timetable has helped you, please **share it with other students** preparing for course registration. We will keep improving it so that more students can use it conveniently.

Thank you.
