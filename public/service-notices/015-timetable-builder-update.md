안녕하세요, SYU CAMPUS입니다.

수강신청을 준비하면서 여러 시간표를 더 편하게 비교할 수 있도록 **시간표 짜기 페이지**를 업데이트했습니다.

강의를 찾는 과정부터 여러 시간표 비교, 저장과 공유까지 실제 사용 흐름을 기준으로 전반적인 기능과 화면 구성을 개선했습니다.

---

## 업데이트된 기능

### 더 자세한 강의 검색과 필터

- 과목명, 교수명, 과목 코드뿐 아니라 **영역, 비고, 학과, 단과대, 장소, 수업시간**으로도 강의를 검색할 수 있습니다.
- 여러 요일을 선택하면 선택한 요일 중 하나라도 수업이 있는 강의를 확인할 수 있습니다.
- 시작 교시와 종료 교시를 지정해 해당 범위와 겹치는 강의를 찾을 수 있습니다.
- 검색어가 영역이나 비고 등에 일치한 경우 어떤 정보에서 검색됐는지 함께 표시합니다.

### 보기 편해진 주간 시간표

- 주간 시간표는 기본적으로 **월요일부터 금요일, 1교시부터 9교시**까지만 표시합니다.
- 선택한 강의에 늦은 교시가 있으면 필요한 마지막 교시까지 순서대로 자동 확장됩니다.
- 토요일 또는 일요일 강의를 선택하면 필요한 주말 요일까지 자동으로 추가됩니다.
- 데스크톱에서는 주간 시간표와 강의 추가 패널의 높이를 맞추고, 시간표 페이지를 더 넓게 사용할 수 있도록 정리했습니다.

### 여러 시간표 선택과 비교

- 데스크톱에서 **여러 시간표로** 버튼을 누르면 2개부터 최대 4개까지 시간표를 함께 비교할 수 있습니다.
- 각 강의에서 1~4번 시간표를 직접 선택해 원하는 조합에 추가할 수 있습니다.
- 시간표 복제와 삭제를 지원하며, 한 시간표를 세로로 스크롤하면 나머지 시간표도 같은 위치로 이동합니다.
- 모바일과 태블릿에서는 선택한 시간표 하나를 표시하고, 저장된 다른 시간표는 그대로 보존합니다.

### 저장과 공유

- 직접 구성한 시간표는 현재 브라우저에 30일간 자동 저장됩니다.
- 링크를 만들어 단일 시간표 또는 여러 시간표 구성을 공유할 수 있습니다.
- **이미지 저장** 버튼으로 현재 시간표를 PNG 이미지로 내려받을 수 있습니다. 여러 시간표를 사용 중이면 최대 4개의 시간표가 한 이미지에 함께 저장됩니다.

업데이트된 기능은 [시간표 짜기 페이지](/academic/timetable)에서 이용할 수 있습니다.

## 이용 중 불편하거나 개선이 필요한 부분을 알려주세요

시간표를 사용하면서 아래와 같은 사항을 발견했다면 화면 하단의 **사이트 문의하기**를 통해 편하게 알려주세요.

- 검색되지 않는 강의 정보나 잘못 표시된 시간
- 특정 화면 크기에서 불편한 레이아웃
- 시간표 선택, 공유 또는 이미지 저장 중 발생한 문제
- 추가되었으면 하는 간단한 기능이나 사용성 개선 의견

보내주신 제보와 건의사항은 확인 후 데이터 수정과 서비스 개선에 참고하겠습니다.

시간표 기능이 도움이 되었다면 수강신청을 준비하는 주변 학우들에게도 **많이 공유해 주세요**. 더 많은 학생이 편리하게 사용할 수 있도록 계속 개선하겠습니다.
