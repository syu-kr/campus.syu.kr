SYU CAMPUS는 설치하지 않아도 웹에서 사용할 수 있습니다. 자주 이용한다면 홈 화면에 추가해 아이콘으로 바로 열어 보세요. 이 설치 방식을 PWA라고 합니다.

## 에브리타임 등 앱 안에서 열었다면

앱 내부 브라우저에서는 설치 메뉴가 없거나 외부 브라우저로 이동하는 기능이 제한될 수 있습니다. 먼저 iPhone·iPad는 Safari, Android는 Chrome에서 열어 주세요.

1. 설치 안내에 **Safari에서 열기** 또는 **Chrome에서 열기** 버튼이 보이면 눌러 보세요. 앱과 기기 설정에 따라 이동하지 않을 수 있습니다.
2. 이동하지 않으면 현재 앱의 메뉴나 공유 메뉴에서 **외부 브라우저에서 열기**와 비슷한 항목을 찾아보세요. 메뉴 이름과 제공 여부는 앱마다 다릅니다.
3. 해당 메뉴도 없다면 설치 안내의 **주소 복사**를 누르고 Safari 또는 Chrome을 직접 열어 주소창에 붙여 넣으세요. 복사가 막히면 표시된 주소를 길게 눌러 복사하거나 `https://campus.syu.kr/`를 직접 입력하세요.

설치 안내의 주소는 SYU CAMPUS 공개 홈페이지입니다. 현재 보고 있는 페이지나 로그인·초대 링크를 옮기는 기능은 아닙니다. 브라우저나 설치된 웹앱을 바꾸면 로그인 상태, 설정, 기기에 저장한 데이터가 다를 수 있으며 자동 이전을 보장하지 않습니다.

## iPhone·iPad에서 홈 화면에 추가하기

1. Safari에서 [SYU CAMPUS](/)를 엽니다.
2. **공유 → 홈 화면에 추가**를 선택합니다. 공유 버튼 위치는 OS 버전과 화면 설정에 따라 다를 수 있습니다.
3. **웹 앱으로 열기** 옵션이 표시되면 켠 뒤 이름을 확인하고 **추가**를 누릅니다.
4. 홈 화면에 생긴 SYU CAMPUS 아이콘으로 실행합니다.

Safari는 안내를 따라 하기 위한 권장 브라우저입니다. 다른 브라우저의 홈 화면 추가 지원은 OS와 브라우저 버전에 따라 다릅니다.

## Android에서 설치하기

1. Chrome에서 [SYU CAMPUS](/)를 엽니다.
2. 홈의 **앱 설치** 버튼을 누릅니다. 설치 확인 창을 지원하고 준비된 브라우저에서는 확인 창이 열립니다.
3. 확인 창이 뜨지 않으면 Chrome 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 찾아 진행합니다. 메뉴 이름과 설치 방식은 브라우저·기기마다 다릅니다.
4. 설치 후 홈 화면이나 앱 목록에서 SYU CAMPUS를 엽니다.

삼성 인터넷 등에서도 브라우저가 제공하는 설치 또는 홈 화면 추가 메뉴를 사용할 수 있습니다. 단순 바로가기로 추가되면 실행할 때 브라우저 화면이 표시될 수 있습니다.

## 설치 버튼이나 메뉴가 보이지 않나요?

홈의 설치 안내를 닫았더라도 **더보기 → 앱 설치 안내**에서 다시 확인할 수 있습니다. 설치 확인 창이 지원되지 않거나 준비되지 않았을 때도 기기별 방법과 주소 복사 기능을 이용할 수 있습니다.

앱 내부 화면이 아닌 Safari나 Chrome에서 열었는지 먼저 확인하세요. 이미 설치했다면 홈 화면이나 앱 목록을 확인하고, 메뉴가 계속 없으면 OS와 브라우저의 업데이트 여부를 확인해 주세요. 설치 없이 웹으로 계속 이용해도 됩니다.

## 설치 후 사용과 데이터

- **공지 알림:** 서비스 공지와 주요 캠퍼스 소식을 알림으로 받고 싶다면 홈 화면의 SYU CAMPUS 아이콘을 연 뒤 **더보기 → 알림 및 개인정보 → 알림 켜기**를 선택하세요. 알림을 지원하는 환경에서 권한 요청을 허용하면 받을 수 있고, 같은 화면에서 끌 수 있어요.
- **인터넷 연결:** 공지, 학식, 셔틀 등 주요 정보 조회에는 인터넷 연결이 필요합니다. 설치했다고 모든 기능을 오프라인으로 사용할 수 있는 것은 아닙니다.
- **업데이트:** 웹 변경사항은 보통 재설치 없이 반영됩니다. 이미 열린 화면에는 즉시 보이지 않을 수 있으므로 필요하면 새로고침하거나 닫았다 다시 열어 주세요. 반영 시점은 연결 상태와 브라우저에 따라 달라질 수 있습니다.
- **저장 공간:** 사용하는 용량은 기기, 브라우저, 저장된 데이터에 따라 달라집니다.
- **삭제와 재설치:** 기기의 앱 제거 또는 홈 화면 삭제 메뉴를 이용할 수 있습니다. 웹앱을 삭제하거나 브라우저 데이터를 지우면 시간표 초안, 졸업요건 진행 상태 등 기기에 저장한 내용이 사라질 수 있습니다. 필요한 내용은 먼저 별도로 보관해 주세요. 재설치해도 이전 데이터가 복원된다고 보장할 수 없습니다.
