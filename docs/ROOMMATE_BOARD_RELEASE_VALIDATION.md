# 룸메이트 게시판 공개 전 검증표

2026-10-04 기준 **공개 대기** 상태다. [최종 계획](./ROOMMATE_BOARD_PLAN.md)의 집중 검증 26항목과 [배포 절차](./ROOMMATE_BOARD_DEPLOYMENT.md)의 시험표를 실제 실행 범위에 연결한다. 아래의 자동·격리 환경 통과를 프로덕션 공개 완료로 해석하지 않는다.

사용자는 **검증·PR 완료 후 조건 충족 시 공개**를 선택했다. 현재 PR은 열린 상태로 유지하며 main 병합·프로덕션 배포·기능 활성화·공지 게시를 진행하지 않는다. 공개 완료 공지는 출시용 원고이며 실제 공개 시점에 날짜와 동작을 다시 확인한다.

`완료`는 표에 적은 환경과 검사 범위에서 실행 결과를 확인했다는 뜻이다. `미실행`은 검사를 수행하지 않았다는 뜻이며, `운영 준비 필요`는 운영 설정을 갖추고 해당 환경에서 다시 확인해야 한다는 뜻이다. 한 항목에 여러 상태가 있으면 일부 증거만 확보된 상태다. 실제 메일함과 기기 결과를 모의 응답이나 viewport 검사로 대체하지 않는다.

이전 문서에서 `roommate_posts(status + created_at)`을 READY로 기록한 것은 필드 조합이 같은 다른 컬렉션의 인덱스를 대조한 오류였다. 실제 READY 항목은 `site_inquiries`와 `campus_tip_suggestions`였다. 운영 인덱스의 `name`에 포함된 `collectionGroups`까지 대조해 정정했으며, **룸메이트 기능에 필요한 인덱스는 4개 모두 미준비**다.

| 컬렉션 그룹 | Query scope | 필드 순서 | 최신 운영 상태 |
| --- | --- | --- | --- |
| `roommate_posts` | COLLECTION | `status` ASC, `created_at` DESC | MISSING |
| `roommate_posts` | COLLECTION | `status` ASC, `recruit_until` ASC | MISSING |
| `roommate_reports` | COLLECTION | `status` ASC, `expires_at` ASC | MISSING |
| `api_rate_limits` | COLLECTION | `metric` ASC, `window_start` ASC | MISSING |

발송 한도의 기준은 [Firebase Authentication 한도](https://firebase.google.com/docs/auth/limits)이며, 이메일 주소 확인 메일 한도를 로그인 링크 한도로 대신 적용하지 않는다. 인덱스 정의는 [저장소 설정](../firestore.indexes.json)을 기준으로 한다. 에뮬레이터 성공은 운영 인덱스 준비의 증거가 아니다.

## 공개 판정에 남은 조건

1. 이번 최종 코드의 전체 검사는 394개와 production 빌드까지 통과했다. PR 최종 원격 SHA의 필수 CI 결과를 다시 확인한다.
2. 사용자가 예정한 Blaze 전환 후 실제 요금제와 충분한 로그인 링크 발송 한도를 확인한다.
3. Production의 owner 비밀값·세 플래그·프로젝트/계정 일치, 허용 도메인, Rules와 필요한 인덱스 4개를 준비하고 실제 운영 조회로 확인한다.
4. 표의 미실행 메일·기기·관리자/관측·중지/복구 시험을 실제 대상에서 수행한다. 실행하지 못한 항목은 미완료로 남긴다.
5. 보호 브랜치 CI→동기화→해당 SHA의 Production 배포와 HTTPS 실동작을 확인한 뒤 공개 상태를 판정한다. 공지 원고 작성·수정만으로 실제 공개 증거를 대신하지 않는다.

이 문서에는 테스트 메일 주소, 링크 query, 인증/세션 token, 쿠키 원문, 비밀값과 서비스 계정 원문을 기록하지 않았다.
