# 사용자 문구와 예외 처리 점검

2026-10-26, M3 서비스 구현 작업 트리 기준. 학생 화면의 한국어·영어 사전과 각 문구를 표시하는 조건, 관리자 오류 표시, 공통 오류·404 화면을 점검했다. 학교 공지·식단·강의·법적 고지의 원문은 문체 정리를 이유로 바꾸지 않았다. 이는 문구와 사용자 복구 흐름의 점검이며 외부 정보의 사실관계 전수 검증이나 보안 감사는 아니다.

## 발견 사항과 반영

| 화면·위치 | 문제 | 반영 |
| --- | --- | --- |
| 모든 화면의 문의 모달, `/campus/campus-tips/suggest` | 네트워크·JSON 해석 오류 원문 노출, 영문 화면의 한국어 제한 메시지, 형식이 잘못된 200 응답에서도 입력값을 지우며 성공 표시 | 알려진 검증 코드는 기존 입력란에 표시. 알 수 없는 실패는 번역된 안내로 처리하고 초안을 보존. `success: true` 확인 후에만 성공·초기화. 응답을 못 받으면 접수 여부 미확정과 재제출 중복 가능성 안내 |
| `/more/meet` | 원시 예외 노출, 방 삭제 권한 저장 실패를 알리지 않음 | 입력값 유지·사용자용 재시도 안내. 초대 링크는 유지하고 방 삭제 권한이 저장되지 않았음을 안내 |
| `/more/meet/[roomId]` | 방 조회 오류의 기본 문구가 참여 정보 저장 실패. 초기 실패 화면에 재조회 액션 없음 | 조회·저장 오류 분리, 같은 방을 다시 불러오는 버튼 추가. 알 수 없는 오류 원문 숨김. 닉네임·선택 시간·수정 권한 유지 |
| `/academic/timetable` | 강의/공유 API 오류 원문 표시, 성공한 빈 목록도 조회 실패 제목, 복사 실패 원인을 권한 문제로 단정 | 번역된 오류와 정상 빈 목록을 구분. 공유 실패 후 선택 강의 유지, 링크 확인·직접 복사 안내. 이전 정보 경고와 원본 확인 경로 유지 |
| `/academic/graduation` | 만료 기능이 없는 공유 주소에 만료 가능성 안내 | 전체 주소 확인 또는 새 링크 요청으로 수정. 입학·학과 선택지, 진단 조건, 저장·가져오기 규칙 유지 |
| 룸메이트 목록·작성·내 글·인증 | 서버 500을 입력 확인으로 안내, 읽지 못한 성공 응답을 빈 객체로 처리, Firebase/접속 상태 생성 표현 노출 | 서버 장애와 입력 오류 분리. 읽을 수 없는 성공 응답은 실패 처리. 비정상 401에서도 비공개 화면 초기화 유지. 로그인·메일 이용 중심으로 표현 변경 |
| 홈·학식 | 미수신/설정 누락을 ‘준비 중’으로 단정, 지난주·미래 식단을 현재 표시 중인 것처럼 제목 작성 | 현재 확인할 수 없는 정보와 이전·미래 식단을 구분. 불필요한 처리 과정 설명을 줄이고 이용 전 확인 안내 |
| 학사일정·졸업요건·연락처 요약 | 정해진 데이터 집계를 ‘AI 답변 요약’으로 표기 | ‘핵심 안내’로 변경. 실제 AI 공지 요약의 표시는 유지 |
| 전체 검색·날씨·체육시설·출처 소개 | 내부 데이터/API 표현, 실패·빈 상태에서 다음 행동이 불명확한 문구 | 실제 서비스 내용, 확인하지 못한 항목, 다음 확인 방법 중심으로 정리 |
| 404 | 무작위 농담·노래 문구가 오류 원인과 복귀 안내보다 앞섬 | 일관된 ‘페이지를 찾을 수 없습니다’와 기존 홈·문의 액션 유지 |
| 최상위 오류 화면 | 영문 경로에서도 한국어만 표시 | 실패한 루트 Provider에 의존하지 않고 경로의 언어에 맞는 복구 안내. 오류 보고·재시도·청크 오류 새로고침 유지 |
| 관리자 문의·룸메이트 관리 | 인증 SDK·네트워크 예외를 그대로 표시할 수 있음 | 구조화된 운영·권한 안내는 유지하고 예상하지 못한 예외는 조회/변경 결과 확인 안내로 대체. 원문 부재를 보존 기한 삭제로 단정하지 않음 |

## 그대로 유지한 안내와 조건

- 학사/장학/학과/학교생활 공지·공모전·서비스 공지의 원문, AI 참고 고지, 페이지·검색·필터·복귀 조건.
- 셔틀·대중교통·도서관의 확인 시점과 운행/좌석 정보의 한계. 조회 실패를 휴무·운행 종료로 바꾸지 않음.
- 지도 실패 시 건물 검색·시설 목록과 외부 콘텐츠/쿠키 설정 확인 안내. 쿠키를 모든 실패의 원인으로 단정하지 않음.
- 졸업 최종 판정은 SU-WINGs·학과 확인, 개인정보 처리·동의·인증과 알레르기 안내. 기술/서비스 제공자 이름이 필요한 법적 설명은 유지.
- 브라우저 저장 불가, 삭제/덮어쓰기 확인, 클립보드 실패 시 직접 복사, 졸업요건 파일 내보내기 등 실제 손실을 막는 안내.

## 검증

로컬 증거는 Git 제외 경로 `output/playwright/copy-recovery/`에 보관한다. 실제 문의·인증 메일·푸시·게시글 쓰기와 운영 배포는 하지 않았다. 접수 예외 테스트는 모의 응답을 사용한다.

- 타입 검사, i18n 검사, 변경 파일 ESLint, `git diff --check` 통과. 최종 Next.js 최적화 빌드의 TypeScript 검사와 정적 페이지 62개 생성 통과.
- 전체 단위 테스트 최종 실행: 185개 파일·1,678개 테스트 중 1,677개 통과. 나머지 1개는 Windows의 ESLint 하위 프로세스 실행 시간 초과였다. 테스트 제한·소스 수정 없이 해당 파일을 단독 재실행하여 6개 모두 통과했다. 전체 실행 한 번이 모두 통과했다고 해석하지 않는다.
- 앞선 실행에서 발견한 학식의 과거/미래 안내 제목 중복은 문구를 구분해 수정했다. 접수 모달 테스트의 일시적인 시간 초과와 함께 두 파일 45개 테스트를 분리 재실행하여 통과했다. 최초·최종·재실행 로그를 구분해 보관한다.
- 기본 화면: 기존 37개 경로 × 1440/390px = 74개 진입 화면 확인. 가로 넘침과 브라우저 실행 오류 없음. 보호된 룸메이트·관리자 경로는 비로그인 안내를 확인했으며 실제 로그인한 사용자의 운영 데이터를 조작한 검증은 아니다.
- 예외·복귀: 한국어/영어 × 1440/390px에서 문의·제보의 잘못된 200 응답, 내용 유지, 모의 성공 후 창 닫힘/목록 복귀, 일정 방 실패 후 같은 방 재조회, 시간표 정상 빈 목록, 404를 확인했다. 28개 화면/복귀 기록, 가로 넘침·브라우저 실행 오류 없음. 실제 쓰기는 전송하지 않았다.
- 네트워크·JSON 해석 실패, 필드 검증 초점, 제한 응답, 브라우저 저장 불가, 로그인 재시도, 영문 최상위 오류는 단위 테스트로 추가 확인했다. 정상 빈 목록과 오류, 입력 오류와 서버 장애, 접수 확인 실패와 성공을 구분한다.
- 모바일 접수 결과 제목은 단어 중간에서 끊기지 않도록 공통 모달에 줄바꿈 규칙을 적용하고 최종 빌드 캡처를 확인했다.

학교 원문·서비스 공지 본문의 사실관계, 실제 메일/푸시 수신, 실제 인증 후 운영 쓰기, 실기기·오프라인·모든 외부 장애 조합까지 검증한 것은 아니다. 브라우저 자체의 기본 유효성 문구는 브라우저/OS가 제공하는 안내이며 사이트 번역 사전의 교정 대상과 구분한다.

시간표 폰트는 기존 생성 지침에 따라 새 안내의 35개 글자를 추가했다. 67,996 → 74,448바이트(+6,452바이트). 글자 포함 여부·400/600/700 윤곽과 폭·숫자 기능·바이너리 재현성 검사를 통과했다. 실제 기기나 운영 Core Web Vitals 측정 결과로 해석하지 않는다.
