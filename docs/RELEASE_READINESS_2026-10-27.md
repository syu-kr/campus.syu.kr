# 2026-10-27 출시 준비 판정

후속 코드 보완과 현재 최종 후보는 [배포 직전 보완·재검증](PRE_DEPLOY_FIXES_2026-10-27.md)을 따른다. 아래 표와 수치는 각각 명시한 앞선 실행의 기록이다.

점검 예정 시간은 **2026-10-27(화) 16:00–17:00 KST**다. 17시는 예정 종료 시각이며 실제 확인이 끝나기 전에는 완료를 선언하거나 안내 배너를 내리지 않는다. 이번 준비 작업에서 main 병합·프로덕션 배포·활성 공개 데이터 전환·Actions 실행은 하지 않았다.

사용자 확인 후 점검 안내의 표시 방식을 상단 띠에서 **가운데 뜨는 팝업 공지**로 변경했다. 현재 CMS 게시본은 팝업이며, 닫기·오늘 그만 보기·배경 dim을 지원한다. 후속 검증과 동작은 [팝업 전환 기록](BANNER_POPUP_2026-10-27.md)을 따른다. 아래 기존 상단형 배너 수치는 해당 후보의 과거 검증이다.

전체 잔여 작업, 배포 후 검사와 Firebase/Pages 전환 순서는 [출시 실행표](RELEASE_MIGRATION_RUNBOOK_2026-10-27.md)에 모았다. 화면 근거는 [디자인 검증](RELEASE_DESIGN_VERIFICATION_2026-10-27.md), 보안 범위와 한계는 [보안 검증](RELEASE_SECURITY_VERIFICATION_2026-10-27.md)을 따른다. 기존 [배포 전 진행 기록](PRE_RELEASE_PROGRESS_2026-10-27.md)의 과거 수치와 이번 실행을 구분한다.

## 이번에 발견해 보완한 사항

1. **상단 이미지 잘림·과대 배치**: 넓은 광고 비율로 잘라 보이던 사진을 상단 배너에 한해 전체 표시한다. 데스크톱은 사진과 문구를 나란히, 모바일은 설명을 전체 폭에 둔다. 홈 배너·기존 선택지·이동 조건은 유지한다.
2. **첫 배너 조회 실패 뒤 긴 빈 화면**: 서버 초기 목록이 비었을 때 클라이언트가 30초를 기다리던 문제를 즉시 재조회하도록 보완한다. 정상 서버 목록이 있으면 불필요한 최초 요청을 추가하지 않는다.
3. **알림 수집 저장소 누락**: 일일 알림 Actions에 `PUBLIC_DATA_BACKEND`와 버킷 변수 전달을 추가한다. 발송 시각·대상·중복 방지 조건은 유지하며 실제 알림은 보내지 않았다.
4. **영어 셔틀 지명 누락**: `구리 bound`를 `Guri bound`로 표시하도록 기존 공개 이름 사전을 보완한다. 한국어 원본과 노선 식별자는 유지한다.
5. **배너의 늦은 삽입으로 화면 이동**: 느린 기기·네트워크 표본에서 공통 약 0.194 이동이 확인됐다. 기존 1초 조회 제한을 유지하면서 첫 HTML에 배너를 포함했다. 참조가 사라진 배너 래퍼도 제거했다. 최종 수치는 아래에 기록했다.

## 검증 결과와 범위

- **37경로 전체**: 최종 빌드의 KO/EN × 1440/390px **148뷰 PASS**, 화면 실패·브라우저 예외·fixture로 대체한 공개 필드의 잔여 한글 0. 번역 실패→재시도 4건과 언어 왕복도 통과했다. 이 순회는 Google 호출 0인 번역 fixture이며 실제 공급자 품질은 위 3필드 표본과 구분한다.

- 이미지 업로드·실제 Google 표본·TTL/IAM 조회는 위 표의 정상 기능 확인이다. 모의 보안 검사와 별도 근거이며 운영 시스템을 공격 대상으로 삼지 않았다.

**외부 연결 예외는 남아 있다.** 최종 순회에서 셔틀 실시간 API는 502를 4회 반환했고 정적 시간표·오류 안내를 확인했다. 없는 일정 방 `unavailable`은 의도된 복구 경로에서 404를 4회 반환했다. 로컬 지도는 외부 SDK 연결 실패 안내와 건물 검색·시설 목록을 표시했으며, Production의 허용 도메인·쿠키/CSP 연동은 별도 확인한다. 나머지 화면 성공을 이 외부 연결의 정상 판정으로 확대하지 않는다.

## 배너 운영

제목은 **서비스 업데이트 안내**, 본문은 다음과 같다.

> 2026.10.27(화) 16:00–17:00(KST) 서비스 업데이트와 데이터 이전을 진행합니다. 일부 기능이 잠시 원활하지 않을 수 있습니다.

- 팝업 공지·우선순위 1000. 이미지 전체와 안내문을 표시하고 닫기·오늘 그만 보기·Esc·바깥 클릭을 제공한다. 현재 탭의 닫기는 sessionStorage, 오늘 그만 보기는 한국 시간 다음 자정까지 localStorage에 저장한다. 새 게시 revision이면 다시 표시한다. 저장이 차단돼도 현재 화면에서 닫을 수 있다. 새 버전이 실제 배포되면 표시된다. Git merge 순간에 기존 배포의 HTML이 바뀌는 것은 아니다.
- 17시 자동 종료를 두지 않았다. 완료 확인 뒤 `/admin`의 배너 목록에서 해당 제목을 선택해 **게시 중단**한다. 삭제·보관이나 다른 배너 수정은 필요하지 않다.
- 게시 중단은 공개 목록과 클라이언트 갱신에 반영되며 이미 열려 있는 탭에는 캐시·폴링 간격이 적용될 수 있다. 이미지 자체는 공개 URL과 immutable 캐시가 남으므로 게시 중단을 이미지 영구 삭제로 해석하지 않는다.
- 배너 API 장애 때문에 캠퍼스 기능 전체가 중단되지 않도록 실패 경로를 유지한다. 관리·민감 페이지의 기존 비노출 정책도 유지한다.

## 출시 전 결정

코드·로컬 실연결이 정상이어도 아직 Firebase 운영 전환 완료는 아니다. 우선 **새 UI 배포 확인 → 최신 자료 적용 → Actions 생산자 전환 → Vercel 소비자와 공지 DB 전환 → 실제 운영 확인** 순서로 진행한다. Pages 종료는 첫 정상 Firebase 발행, 만나의집 fallback/구주소 의존 해소, 복구 기준선 확인 뒤의 별도 단계다.

정적 로고·폰트·아이콘·OG·기본 i18n·정책 문서를 Firestore로 옮길 필요는 없다. 서비스 공지 MD와 공개 JSON은 정상 이전·구버전 호환·장애 fallback을 확인한 뒤 정리하며, 최초 출시와 함께 일괄 삭제하지 않는다.
