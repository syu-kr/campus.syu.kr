# 룸메이트 게시판 탭 복귀 및 메뉴 수정 검증

2026-10-04. 최신 main `004d8363`에서 `codex/roommate-tab-refresh-and-header`를 생성했다.

## 변경

- 일반 탭 숨김·복귀는 글과 작성 중 입력을 가리지 않는다. 세션 확인은 마지막 요청으로부터 5분 이상 지난 복귀에만 백그라운드로 수행한다.
- 모집 목록·상세·내 글은 5분간 최신 자료로 취급한다. 실패 후에도 5분 동안 탭 복귀 자동 재시도를 제한하며 사용자의 재시도·필터 적용·글 변경 후 갱신은 즉시 수행한다.
- 최초 진입과 실제 pagehide/BFCache 복원은 새 인증 확인을 기다린다. 고정 만료는 탭 복귀 시 간격 제한보다 먼저 확인하고, 도착 시 이미 만료된 응답도 자식을 마운트하지 않는다.
- 로그아웃·401·기능 중단·다른 탭의 로그아웃은 글·입력·캐시를 즉시 제거한다. 이전 요청은 화면을 다시 열 수 없다. 로그아웃 진행·실패 중 게시판 메뉴 이동을 차단한다.
- 공통 헤더에 `‹ 캠퍼스` 출구를 제공하고 로그아웃을 모집 목록·내 글 관리·모집글 작성 메뉴와 같은 줄에 배치했다. 최초 확인·오류·기능 중단에도 출구와 로그아웃은 남는다.
- 데이터 API의 서버 인증, HTTP no-store, 고정 세션 기간 및 캐시 삭제는 유지한다. 새 의존성·운영 설정 변경은 없다.
