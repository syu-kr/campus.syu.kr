# Hallmark UI/UX 보완과 공개 콘텐츠 영어 표시 구현

2026-10-26. 현재 M3 서비스 구현에 감사 보고서 U01–U10과 공개 콘텐츠 번역을 반영했다. 기존 한국어 원본·선택지·검색 조건·검증·저장·복귀 흐름을 유지했다. 실제 배포는 수행하지 않았다.

서비스 공지 012의 해외 위치 자동 영문 전환 안내를 실제 `/en`·저장된 언어 선택 정책에 맞췄다. 최종 화면 검증에서 추가로 찾은 일정 방 조회 실패 화면의 h1을 KO/EN에 보완했다. 이미 영어 별칭을 제공하는 홈 셔틀은 중복 Google 번역 버튼을 표시하지 않는다.

## 영어 콘텐츠와 인라인 번역

- 기존 영문 원문 012와 새 영문본 18개를 연결해 서비스 공지 19개 모두 EN에서 영어 제목·본문을 제공한다. 원본 전체 SHA256을 LF 정규화해 비교하고, 원문 변경 시 검수되지 않은 영문본을 재사용하지 않는다.
- 슬러그·작성자·날짜·정렬·공지 수·10+9 페이지 이동·복귀는 유지한다. 원문과 영문본의 링크 목적지·제목 단계를 대조했다. 과거 공지의 기능 설명은 당시 원문을 따른다.
- 공개 공지·요약, 공모전, 두 식당의 메뉴, 일정, 공개 꿀팁, 전화부 설명, 지도, 도서관 운영시간, 셔틀, 강의, 졸업 참고 요건에 현재 화면의 영어 reader 또는 번역 전환을 연결했다.
- 서버는 13개 허용 유형의 공개 ID·필드를 직접 조회한다. 임의 텍스트·URL이나 개인 입력을 전달하는 API는 만들지 않았다. 원문 해시·처리 버전 캐시, 공유 요청 제한·일일 문자 예약·동시 요청 통합·숫자 보존·원문 변경 검사·실패 복귀를 적용했다.
- 고정 노선·열람실 이름은 표시 별칭을 제공하며 한국어 원본과 식별자를 보존한다. 번역 결과는 기존 검색 색인이나 옵션 값으로 사용하지 않는다.
- 원문 언어가 한국어일 때만 EN에서 번역 버튼을 표시한다. 한국어 UI에 빈 번역 wrapper나 불필요한 간격을 추가하지 않는다. 액션은 링크·버튼 내부에 중첩하지 않는다.
- Google Translate 공식 귀속 배지는 원본 그대로 로컬 자산으로 제공한다. 위젯이나 전역 DOM 교체, 외부 번역 페이지로의 이동은 사용하지 않는다. 새 런타임 의존성은 추가하지 않았다.

인증은 사용자의 선택에 따라 **미설정 상태까지** 구현했다. 실제 로컬 API의 GET은 available=false, POST는 503을 반환한다. 실패 시 원문·URL·localStorage와 기존 전화·이동 액션을 유지했다. 성공·원문 복귀·재사용은 로컬 모의 응답으로 확인했으며 Google에 실제 요청하지 않았다.

상세 설정·자료 경계·TTL·비용 보호·운영 검토는 [콘텐츠 번역 운영](CONTENT_TRANSLATION.md), 기본 사전 기준은 [i18n 정책](I18N_POLICY.md)을 따른다.

총 170개 화면의 초기 회귀와 마지막 수정 후 12개 기록을 별도로 보존했다. 확인한 화면에서 가로 넘침·pageerror·중첩 번역 액션은 없었다. 첫 전체 테스트에서 병렬 실행으로 시간 초과된 두 파일은 분리 재검사 후 통과했고, 동시 실행 수를 제한한 전체 및 최종 전체 검사도 모두 통과했다. 시간 제한을 늘려 실패를 숨기지 않았다.

원본 로그·캡처·수집기는 Git에서 제외되는 `output/playwright/hallmark-remediation/`와 `output/playwright/hallmark-audit/`에 둔다. 기존 예시 HTML을 서비스 검증 결과로 계산하지 않았다. 기존 작업의 변경사항도 보존했다.

## 남은 운영 경계

Google 인증·과금 프로젝트, 운영 Firestore TTL·권한, 실제 번역 품질·지연은 활성화 전에 별도로 확인해야 한다. 키·운영 데이터·메일·푸시·배포는 변경하지 않았다. 실제 iOS/Android, Safari/Firefox, 실사용 스크린리더와 로그인 후 운영 데이터의 검증은 이번 로컬 Chromium 회귀 범위에 포함하지 않았다.
