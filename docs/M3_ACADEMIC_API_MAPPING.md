# M3 학사 화면의 실제 데이터 연결

2026-10-25 구현 기준. 시안의 fixture, 미리보기 변환기, 확인창 어댑터는 서비스 코드에 포함하지 않았다. 시간표는 기존 `GET /api/lecture/timetable`과 `LECTURE_TIMETABLE_URL` 원본을 사용하며, 6시간 서버 캐시·동시 요청 병합·원본 장애 시 마지막 정상 데이터와 오래된 상태 표시를 유지한다. 공유는 기존 `POST /api/lecture/timetable/shares`, `GET /api/lecture/timetable/shares/[shareId]`, 소유자 토큰을 전달하는 `DELETE /api/lecture/timetable/shares/[shareId]`에 연결되어 있고, 실제 저장소는 `FIREBASE_SERVICE_ACCOUNT`로 초기화하는 Firestore이다. 최대 4개 비교안, 학기 불일치·누락 과목 검증, 30일 브라우저 초안, 공유 소유권과 이미지 내보내기를 보존했다. 졸업요건은 `lib/graduation.ts`가 가져오는 기존 요건·학과 규칙·2026 검증 교육과정·출처 JSON을 사용하며, 입학년도와 소속·입학유형·전공 형태의 종속 선택지, 초기화 확인, 로컬 저장과 URL 해시 복원은 그대로다. 졸업요건은 학교의 개인별 성적·졸업 판정 API를 새로 연결한 기능이 아니며, 기존과 같이 사용자가 이수 현황을 입력하는 참고용 자가진단이다. 학사일정은 서버에서 `public/data/schedules-major.json`과 실제 공휴일 snapshot을 먼저 전달하고, 클라이언트는 기존 `/data/schedules-major.json` 및 `/api/crawl-data/public-holidays.json` 경로로 갱신한다. 기존 검색어 URL 동기화, 날짜·월 선택, 현재 월 목록 복귀, 공휴일 범위·오래된 데이터·갱신 실패 표시를 유지했다.

새 화면은 선택한 과목만 주간표와 요일별 목록으로 서버 렌더링하고 CSS로 화면 너비에 맞는 보기를 선택한다. 검색 결과 300개는 기존과 같이 현재 사용하는 선택 도구 한 곳에만 마운트한다. 인쇄에는 현재 선택한 요일과 무관하게 일요일·시간 미정 강의까지 모든 선택 강의를 포함하고, 검색 도구·검색 결과는 제외한다. 이미지용 원본 격자는 다운로드할 때만 생성하며 원본 과목 데이터와 내보내기 함수를 그대로 사용한다. 모바일 안내를 닫을 때 입학년도 입력으로 포커스를 복귀시킨다. 졸업요건 변경·전체 초기화는 기존 진도 유무 조건에 따라 공통 M3 확인창을 열고, 취소·Escape 때 선택과 진도를 유지하며 시작 컨트롤로 포커스를 복귀한다. 승인할 때만 원본 종속 선택 초기화와 진도 초기화를 실행한다. 학사일정의 월 이동·검색 초기화는 공통 48px 아이콘 버튼으로 맞추고, 날짜 격자는 사각 구조를 유지한다.

검증은 환경변수 없이 실행한 로컬 테스트와 타입 검사이며, 실제 운영 원본 URL의 응답이나 운영 Firestore 공유 문서 생성·조회·삭제를 증명하지 않는다. 운영 적용 전에는 등록된 `LECTURE_TIMETABLE_URL`, Firebase 서비스 계정과 Firestore 권한, 갱신된 일정·공휴일 데이터로 실제 호출과 공유 소유자 삭제를 확인해야 한다. 이 작업에서 비밀 환경 파일을 복사하거나 새 자격 증명을 만들지 않았다.

로컬 검증 결과: 학사 화면·원본 데이터 규칙·API route를 포함한 집중 테스트 12개 파일의 103개 테스트, 전체 `npm run type-check`, 변경한 학사 TSX 8개 파일의 ESLint가 통과했다. 테스트는 모바일 390px·데스크톱 1440px 학과 Select의 원본 선택지와 필터/초기화, 최대 4개 시간표와 대상 선택, SSR viewport 접근, 일요일·시간 미정 과목의 전체 인쇄 데이터, 상세 모달 복귀, 졸업요건 변경·초기화의 취소/승인/Escape/포커스, 학사일정 검색·월 복귀·공휴일 오류 상태를 검증한다.

실제 Next 개발 서버를 Chromium의 390px·1440px 화면으로 독립 검증했다. 학사 3개 페이지의 총 6개 실제 화면은 모두 HTTP 200, 가로 넘침 0px, JavaScript 예외 0건이었다. 운영 환경변수가 없는 강의 API의 실제 HTTP 500·오류/재시도 화면을 기록했다. 강의 데이터가 필요한 상호작용만 격리된 브라우저 테스트의 응답 주입으로 검증했으며 서비스 소스를 fixture로 대체하지 않았다. Select 트리거와 항목 높이는 모두 48px, 화살표 세로 중심 오차는 0px, 텍스트와 화살표 간격은 12px였고 Escape 포커스·모바일 부모 모달 유지·원본 학과 필터·초기화가 통과했다. 최대 4개 비교안, 졸업요건 취소/승인/포커스, 학사일정 월 이동·검색 초기화와 8px 사각 달력도 양 화면에서 통과했다. 브라우저 인쇄 PDF 양쪽을 다시 열어 월요일·일요일·시간 미정 과목을 모두 확인했고, 전역 메뉴·알림을 제외한 각 1페이지를 Poppler로 렌더링해 확인했다. 증거는 `output/playwright/m3-service/academic-results.json`, `academic-print-check.json`, `academic-*.png/pdf`에 있다. 실제 모바일 기기와 운영 원본 응답·Firestore 쓰기는 확인하지 않았다.

2026-10-26 추가 검증에서는 승인된 원본 환경설정을 프로세스에서 읽어 실행한 실제 Next 서비스와 강의 API를 사용했고, 브라우저 응답 주입을 사용하지 않았다. `GET /api/lecture/timetable`은 HTTP 200으로 2026년 2학기 정규 1,526개 과목을 반환했다. 37개 학과·6개 학년·9개 이수구분과 전체 선택지, 요일 7개·교시 12개가 화면 옵션과 일치했다. 1440px·390px에서 실제 강의번호 82·30·34를 추가하고 학과·학년·이수구분·요일·교시 결합 검색의 원본 예상 결과 1건, 최대 4개 비교안·대상 선택·비교안 삭제·과목 삭제와 다른 선택 과목 유지, 모바일 선택 도구의 닫기/재열기 후 조건·선택 유지가 통과했다. 가로 넘침과 JavaScript 예외는 모두 0이었다. 실제 과목을 인쇄한 PDF를 다시 읽고 화요일·월요일·시간 미정의 세 과목이 각 1페이지에 모두 포함됐음을 확인했다. 증거는 `academic-real-api-results.json`, `academic-real-api-print-check.json`, `academic-real-api*.png/pdf`이다. 공유 API POST/DELETE는 0건으로 유지했고 브라우저 로컬 초안만 변경했다. 실제 모바일 기기·운영 Firestore 쓰기 검증은 여전히 별도 적용 전 확인 항목이다.
