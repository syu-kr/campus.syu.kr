# 학사 화면 데이터·선택·복귀 계약

## 시간표

기존 GET /api/lecture/timetable과 LECTURE_TIMETABLE_URL 원본을 사용합니다. 서버 캐시·진행 중 요청 공유·마지막 정상 데이터의 stale 표시를 유지합니다. 공개 시간표와 인증/소유자 공유 API의 캐시 정책은 [성능 가이드](../PERFORMANCE.md)를 따릅니다.

- 원본 학과·학년·이수구분·요일·교시 선택지와 검색 조합, 최대 4개 비교안·대상 선택을 유지합니다. 특정 조회일의 선택지 수를 코드에 고정하지 않습니다.
- 학기 불일치·누락 강의 검증과 30일 브라우저 초안·과목 삭제/비교안 삭제·다른 비교안의 선택 보존을 확인합니다.
- 공유는 POST /api/lecture/timetable/shares, GET/DELETE /api/lecture/timetable/shares/[shareId]를 사용합니다. 작성자 토큰과 서버 검증·Firestore 권한을 유지합니다.
- 화면은 선택한 강의만 주간 격자·요일 목록으로 렌더링하며 검색 결과는 현재 사용하는 선택 도구에만 마운트합니다. 모바일 도구를 닫고 다시 열어도 조건·선택을 보존합니다.
- 인쇄·이미지에는 일요일·시간 미정 강의를 포함한 모든 선택 강의가 들어가야 합니다. 검색 도구/결과를 제외하고 내보내기용 원본 격자는 다운로드 시에만 만듭니다.

## 졸업요건

서버가 읽은 동일 snapshot의 요건·학과·교육과정·출처 묶음을 전달하고 계산은 lib/graduation-model.ts의 기존 모델을 사용합니다. lib/graduation.ts는 기본 자료 호환 경계입니다. 입학년도·소속·입학유형·전공 형태의 종속 선택, 로컬 저장 키/형식·URL 해시 복원을 유지합니다. 학교의 개인 성적 조회나 공식 졸업 판정 API가 아닌 사용자 입력 기반 자가진단입니다.

기존 진도에 영향을 주는 변경/전체 초기화는 확인창의 승인 후에만 실행합니다. 취소·Escape는 선택/진도를 보존하고 시작 컨트롤로 초점을 돌립니다. 모바일 안내의 닫기는 입학년도 입력으로 복귀합니다. 확인되지 않은 졸업총량을 임의의 양수로 보정하지 않습니다.

## 학사일정

서버의 일정/공휴일 snapshot과 기존 /data/schedules-major.json 및 /api/crawl-data/public-holidays.json 갱신 경로를 유지합니다. 검색어 URL, 날짜·월 선택, 현재 월 복귀, 공휴일 범위·오래된 데이터·실패/재시도를 확인합니다. 월 이동·초기화는 공통 버튼을 사용하되 달력의 정상 사각 격자는 유지합니다.

## 검증 경계

타입·단위·mock·로컬 emulator·운영 원본·실기기를 구분합니다. 실제 강의 원본, Firestore 공유/소유자 삭제, 인쇄/이미지, 저장소 차단과 재방문을 변경 범위에 맞춰 검증합니다. 공개 데이터 전환은 [Firebase 가이드](FIREBASE_CUTOVER.md), 공통 UI와 수동 게이트는 [UI 가이드](UI_DESIGN_GUIDE.md)·[유지보수](MAINTENANCE.md)를 따릅니다.
