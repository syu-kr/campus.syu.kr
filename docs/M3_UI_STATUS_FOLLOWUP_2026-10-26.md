# 선택창·갱신 안내·지도 도움말 후속 정비

## 반영 범위

| 영역 | 반영한 내용 | 유지한 동작 |
| --- | --- | --- |
| 국가/언어 | 기존 공통 M3Select 사용. 푸터 링크 스타일이 입력창의 배경·테두리를 지우지 않도록 범위 지정. 224px 너비·48px 높이, 모바일 16px 글씨, 선택 체크·키보드 탐색·Escape 복귀 | 한국어/영어 선택지, 언어 쿠키, 같은 출처의 문서 이동, query/hash 보존 |

학식 상세·공지·일정은 기존부터 평상시 새로고침이 없었다. 오류 재시도까지 제거하지 않았다. 선택지·검색 조건·검증·저장 키·복귀 규칙 및 외부 API 계약은 수정하지 않았다. 새 의존성을 추가하지 않았다.

## 지도 원인과 사용자 안내의 구분

쿠키가 모든 지도 오류의 원인인 것처럼 표시하지 않는다. 현재 로컬에서는 SDK의 401 도메인 인증 실패를 확인했으며, 쿠키 차단으로 발생했다고 확인된 것은 아니다. [Kakao 공식 가이드](https://apis.map.kakao.com/web/guide/)는 JavaScript 키와 등록한 Web 도메인에서의 실행을 요구한다. 프로토콜·호스트·포트를 포함한 등록 상태는 운영자 점검 사항이며 사용자에게 Kakao 개발자 설정 확인을 요구하지 않는다.

브라우저의 쿠키 허용 여부만으로 개별 외부 콘텐츠 허용 상태를 진단할 수 없으므로 자동으로 원인을 단정하거나 전체 쿠키 허용을 요구하지 않았다. 네트워크·원본 서비스·도메인 설정 문제는 별도로 남을 수 있다. CSP 완화, 프록시 우회, 공급자 설정 변경은 하지 않았다.

## 선택창 감사

- 홈 정류장, 시간표 4개 필터, Meet 간격, 공지 페이지 이동도 390/1440px에서 검사했다. 현재 Chromium에서는 기존 CSS `appearance: base-select`로 M3 토큰에 맞는 펼침을 제공하며 모두 48px 이상의 높이, 12px 모서리, 모바일 16px 글씨였다. 기존 선택지 수는 각각 홈 4, 시간표 13/13/7/10, Meet 3, 검사한 공지 데이터의 페이지 이동 527로 유지됐다.
- 졸업요건은 ChoiceGroup 버튼을 사용하므로 native select 교체 대상이 아니다.
- 안정된 홈·약관에서 언어 팝업은 두 폭 모두 화면 안에 배치됐다. 실제 영어 문서 이동에서 cookie/query/hash 보존과 Escape 초점 복귀를 확인했다.
- 초기 홈은 팝업을 열지 않은 대조군에서도 비동기 콘텐츠로 푸터가 178px 내려갔다. 언어 선택창을 열면서 생긴 회귀는 아니며, 초기 홈 레이아웃 이동은 별도 개선 대상이다.
- `base-select`를 지원하지 않는 브라우저에서는 나머지 native select가 OS 팝업으로 돌아가는 제약이 있다. 이번에 국가/언어에 적용한 M3Select는 OS 팝업에 의존하지 않는다. Safari·Firefox 실기기는 검증하지 않았다.

## 후속 승인: 홈 날씨·검색 제목·A 로고 적용

- 홈 인사말 h1을 캠퍼스 날씨 문장으로 교체하고 날짜 아래의 작은 날씨 중복을 제거했다. 시험 인사 판정과 사용하지 않는 KO/EN 인사 번역 키도 제거했다. 공유 날씨 query·서울 날짜·로딩/오류/이전 관측 상태·live region, 식단의 실제 주말 안내는 유지했다.
- 검색 대화상자의 보이는 제목 줄과 구분선을 제거했다. 대화상자의 접근 가능한 이름은 유지하고, 검색창과 같은 줄에 48px 닫기 버튼을 배치했다. 자동 초점·Escape·닫기 후 초점 복귀·입력 중 메뉴 추천·Enter 검색은 유지했다.
- A안의 두 눈과 작은 미소를 Header/Footer BrandMark에 적용했다. 실제 사용 웹 아이콘과 Android 자산도 맞췄다. 오래된 immutable 이미지 캐시가 U 로고를 계속 보여주지 않도록 새 `-smile.png` 경로를 연결하고 기존 파일은 보존했다. 세부 자산 검사는 [TWA 동기화 기록](M3_TWA_BRANDING_SYNC.md)에 있다.

최종 관련 테스트 9개 파일 93개, 전체 린트·타입·i18n·TWA 준비 검사·최적화 빌드가 통과했다. 새 빌드를 4180에서 실행해 검색 320/390/1440px, 홈 KO/EN 정상 및 KO 오류 6경우, 헤더·푸터 로고 390/1440px를 재검증했다. 화면 밖 넘침·실행·hydration 오류는 없었고 헤더/푸터 마스크 ID는 독립적이었다. 새 아이콘 6개의 HTTP 200 응답과 로컬 원본 해시 일치도 확인했다.

## 추가 정비: 불필요한 안내 제거와 공통 모션

앞선 중립 기준일 표시는 최종 요구에 맞지 않아 완전히 제거했다. `CrawlDataStatus`와 호출·전용 사전·프론트 조회를 삭제했으며, 공지의 별도 보관 출처/날짜 목록도 제거했다. 백엔드 수집 상태 API와 원본 응답 계약은 유지했다. 홈의 정상 갱신 문구·빈 상태 영역, 정상 실시간 배지와 중복 업데이트 줄, 만나의 집의 내부 분석 시각도 제거했다. 조회 실패·재시도, 실제 이전 관측/실시간 데이터의 오래됨, 식단의 해당 주 누락과 원문 게시일은 유지한다.

교통·일정잡기의 기술 설정/JSON 진단은 사용자용 실패 안내로 바꿨다. 문의·캠퍼스 제안은 알려진 필드 오류와 요청 제한의 재시도 시점을 보존하며, 알 수 없는 서버 진단은 일반 실패 안내로 처리한다. 폼 조건과 작성값 유지 정책, API 요청·응답 계약은 바꾸지 않았다. 실제 문의·제안·일정 방 생성은 실행하지 않았다.

| 영역 | 최종 동작 |
| --- | --- |
| 국가/언어 | 흰색 사각 필드에서 지구본이 있는 옅은 파란색 pill로 변경. 256×48px, 모서리 999px. 원래 두 언어·쿠키·query/hash·문서 이동·Escape 초점 복귀 유지 |
| 검색 | 제목 줄과 대화상자 닫기 X를 렌더링하지 않음. 검색창 전체 너비 사용. 바깥 클릭·Escape·초점 복귀·입력 중 메뉴·Enter 검색 유지. 입력 내용 지우기는 닫기 동작과 별도로 유지 |

새 라이브러리는 추가하지 않았다. 시간표·일정 가용 시간 격자에는 누름 확대/축소를 적용하지 않았고, `prefers-reduced-motion`에서는 전환·입장·누름 이동을 끈다.

페이지네이션은 원래 페이지 요청 중 컨트롤이 사라져 표시 이동이 끊겼다. 같은 분류·필터·검색어에서 페이지 번호만 바뀔 때 검증된 이전 전체 건수로 버튼 DOM을 유지하되 본문은 기존 로딩 화면을 표시한다. 검색/필터 변경과 오류에는 이전 건수를 사용하지 않는다. 실제 화면 검토에서는 로딩 중 목록 높이가 2685px에서 544px로 줄면서 스크롤이 튀는 문제도 발견했다. 페이지 클릭 시 기존 목록 높이를 읽고 해당 페이지 로딩 중에만 최소 높이를 유지해 해결했으며, 캐시된 페이지 복귀에도 적용했다. 완료·검색 변경·오류 시 높이를 해제하고 기존 `scroll:false`를 유지했다. 자동 스크롤은 추가하지 않았다.

검증은 관련 17개 파일 178개 테스트, 높이 보완 후 관련 4개 파일 20개 재검사, 전체 타입/린트/i18n/미사용 코드 검사 및 최적화 빌드를 포함한다. Windows에서 생성 파일 `next-env.d.ts` 접근 오류가 발생한 빌드는 파일 접근 확인 후 소스·빌드 설정 변경 없이 재시도해 성공했다. 생성 파일은 커밋에 포함하지 않는다.

실제 API의 로컬 최적화 빌드 4180에서 공지·공모전·학식의 내부 기준 목록과 프론트 상태 조회 0회, 정상 문구 0개, 도서관 7개/실시간 새로고침·오류 후 실제 복구 유지, 검색 320/390/1440px, 언어 선택과 키보드·문서 전환, 공통 모션·움직임 줄이기, hover 메뉴 연결을 확인했다. 선택 이동은 중간 프레임·최종 정렬·대비·같은 표시 DOM·포커스로 검증했고, 느린 페이지 응답과 연속 클릭도 실제 GET으로 확인했다.

## 최상단 상위 복귀 행 제거와 여백 평가

시간표·일정잡기 시작/방·알림 및 개인정보·약관/개인정보·캠퍼스 꿀팁 제안·룸메이트 공통 헤더의 최상단 상위 메뉴 복귀 행을 제거했다. 공지 상세와 서비스 공지 상세의 목록 복귀, 검색 결과 복귀는 본문 뒤로 옮겼다. 이메일 인증의 유일한 취소 링크도 하단 정책 링크 영역으로 옮겨 `clearPendingEmail`을 유지했다. 내부 달력/필터 화살표, 오류 복구와 하단 작업 버튼은 유지했다. 검색의 같은 출처 검증·query·스크롤·선택 링크 초점 복원은 변경하지 않았다.

여백은 **평가만** 수행했다. CSS·Container·폭·padding·gap 수치는 변경하지 않았다. 링크 삭제로 시간표 제목이 64px, 일정잡기 제목이 36px 올라간 것은 해당 행이 사라진 자연 높이 변화다.

[Google의 적응형 레이아웃 가이드](https://developer.android.com/design/ui/mobile/guides/layout-and-content/adapt-layout)는 큰 화면에서 컴포넌트를 무조건 늘리지 않고 최대 폭과 콘텐츠 패널 구성을 사용하도록 권한다. 이는 이 서비스의 유형별 폭을 유지하는 판단을 뒷받침하며, 위 수치가 M3의 의무 규격이라는 의미는 아니다.

## 꿀팁 카테고리 모션·페이지 선택 스타일 통일

캠퍼스 꿀팁의 보기 7항목과 동적 카테고리 행에 기존 `SlidingIndicator`를 적용했다. 보기 변경 시 카테고리 전체·페이지 1 초기화, 카테고리 변경 시 페이지 1 초기화, 검색어 유지와 원본 선택지는 그대로다. 기존 스크롤 wrapper·간격·필터 handler는 변경하지 않았다.
