## 변경과 인증 경계

- 세션 쿠키가 없는 캠퍼스 메뉴는 인증 화면으로 직접 연결한다. 불필요한 게시판 307 응답을 거치지 않는다.
- 캠퍼스 메뉴와 보호 페이지가 Firebase Admin 모듈을 불러오지 않도록 기능 플래그·쿠키 이름을 가벼운 공통 모듈에서 읽는다.
- 보호 페이지는 쿠키를 진입 경로 힌트로만 사용한다. 비공개 컴포넌트는 브라우저의 `auth/session` 검증 성공 후에 마운트하며 모든 데이터 API에서도 서버 인증을 계속 수행한다. 쿠키 유무가 인증을 대신하지 않는다.
- 동시에 발생하는 focus/visibility/pageshow 확인은 현재 유효한 요청 하나를 공유한다. 숨김·로그아웃으로 무효화된 이전 응답은 화면을 다시 열지 못한다. 로그아웃 시작 후에는 확인 요청을 추가로 시작하지 않으며 로그아웃 실패 시에도 글을 숨긴 채 재시도할 수 있다.
- 독립적인 작성자/IP 읽기 제한 트랜잭션은 병렬 실행하되 두 제한 모두 통과해야 한다. 고정된 30일/12시간 만료, 학교 이메일 확인, 비활성화·인증 폐기 확인을 유지한다.
- 캠퍼스의 집 아이콘은 요청받은 SVG 경로·1.5 stroke를 사용한다. 최초 인증 안내의 하단 취소만 제거하고 상단 캠퍼스 이동을 제공한다.
- 약관은 한국어·영어 모두 제1–10조, 개인정보처리방침은 제1–11조 순서로 정리했다. 실제 수집·보유·삭제·위탁·국외 처리를 각 조항에 넣고 운영자를 서상혁 개인(SYU KR 운영 명칭)으로 명시했다.
- 글 등록·수정은 명시적인 개인정보 제공 동의를 요구한다. 수신자·목적·항목·기간·거부 및 철회 방법을 안내하고 서버에서도 `disclosureConsent: true`를 검사한다. 동의 시각과 고지 버전은 서버 문서에 보관하며 학생용 응답에는 넣지 않는다.
- 현행 약관의 사전 공지 약속에 따라 개정 약관은 2026-11-04 시행 예정으로 안내하고, 변경 공지에서 현행 약관 전문도 제공한다. 로딩·화면 개선과 실제 개인정보 처리 고지·공개 동의 및 증빙 보완은 이번 배포부터 적용한다. 게시판의 연락 링크 제공 중단이 외부 카카오 대화 차단을 뜻하지 않도록 문구를 바로잡았다.

## 성능 증거와 적용 한계

수정 전 운영 미인증 경로는 게시판 307의 TTFB 325–409ms와 인증 화면 200의 312–359ms를 합쳐 약 0.65–0.77초가 걸렸다. 2026-10-04 20:58:51 KST에 쿠키 없이 공개 HTTPS GET을 각 3회 재측정한 중앙값은 `/campus` 341ms, 인증 화면 350ms, 게시판의 307 이동 319ms였다. 캠퍼스 첫 요청 2,311ms는 네트워크·TLS·함수 초기화를 분리하지 못하므로 콜드 스타트로 단정하지 않는다. 새 메뉴의 직접 연결은 307 단계를 없앤다. 인증 방문의 SSR 세션 조회도 제거했지만, 새로운 코드의 운영 응답 시간을 측정한 것은 아니다. 배포 후 같은 Node fetch 방식으로 비교하며, 이 수치는 HTML 응답 헤더 도착 시간이고 브라우저 렌더링이나 인증된 API 완료 시간이 아니다.

로컬 에뮬레이터에서는 세션 GET 순차 요청이 107/91/86ms, 동일 제한 문서의 동시 요청 두 개가 3,676/3,493ms, 다음 게시판 GET이 162ms였다. 동시 Firestore 제한 트랜잭션의 경합·재시도이며, dev Strict Mode와 브라우저의 visibility 변화가 겹친 요청을 만들 수 있다. 이 에뮬레이터 수치를 운영 지연으로 단정하거나 요청 제한 제거의 근거로 사용하지 않는다.

## 실제 설정과 남는 확인 범위

운영 메타데이터의 읽기 전용 조회에서 Firestore `asia-northeast3`, Vercel 서버 함수 `iad1`을 확인했다. Firebase Authentication의 미국 처리와 Google LLC의 미국 처리 역할은 [Firebase 개인정보 안내](https://firebase.google.com/support/privacy), [Firebase 약관](https://firebase.google.com/terms), [Google 재수탁사 목록](https://cloud.google.com/terms/subprocessors)에 근거했다. [Google 계약 법인 안내](https://cloud.google.com/terms/google-entity)의 한국 계약 역할과 미국 데이터 처리를 구분했다. 실제 계정의 개별 계약 문서는 제공되지 않았다.

Firebase 인증 사용자 자동 파기는 현재 구현되어 있지 않다. 로그아웃·게시글 삭제가 인증 계정 삭제를 뜻하지 않으며, 실제 삭제 요청 경로와 이 사실을 고지한다. 이번 수정은 확인된 처리 방식에 맞춘 고지와 동의 구현이며 모든 법적 요건 충족을 인증하는 법률 검토 결과가 아니다.

배포 전 운영 Firestore를 읽기만 하여 모집 중이고 기한이 남은 글의 개수와 동의 기록 유무를 집계했다. 현재 활성 모집글 0건, 동의 증빙 없는 활성 모집글 0건이다. 글 내용·이메일·식별자 출력이나 자료 변경은 하지 않았다.

메일 수신·실제 모바일·카카오 인앱·설치 앱의 추가 시험은 이번에 수행하지 않았다. 브라우저 시험은 운영 자격증명을 배제하고 외부 fetch를 차단한 테스트 서버와 가상 학교 이메일로만 수행했다. 실제 학교 메일을 발송하거나 운영 게시글·사용자 자료를 변경하지 않았다.
