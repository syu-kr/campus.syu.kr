# 출시 준비 UI와 사용자 흐름 검증

2026-10-26 KST. 현재 최적화 로컬 서비스 `http://127.0.0.1:4180`를 세 독립 서브에이전트가 실제 Chromium으로 점검했다. **기본 화면과 주요 선택·저장·오류 복구는 동작하지만, 느린 기기의 검색 복귀와 아주 좁은 영어 시간표에 보완이 필요하다.** 제품 코드는 수정하지 않았으며 발견 사항은 [다음 작업 계획](FIREBASE_MIGRATION_RELEASE_PLAN_2026-10-26.md)에 반영했다.

## 우선 보완할 문제

### UX-01 검색 결과가 보인 직후 이동하면 복귀 정보 누락

- **P2 기능 결함, 재현 확인.** 경로 `/?search=시간표` → `/academic/timetable`, 390px, CPU 6배 지연.
- 새 컨텍스트에서 DOMContentLoaded 뒤 첫 시간표 링크가 visible 상태가 되면 즉시 일반 클릭한다. 클릭 직전 DOM에서 검색 결과 제목도 확인했다. 시간표 진입은 성공하지만 `syu-campus-search-return` 세션 값이 없고 `.m3-search-return a`가 나타나지 않는다. 3회 모두 같으며, 같은 조건에서 이동 후 10초를 관찰한 추가 1회도 누락됐다. pageerror는 없다.
- 기대 동작은 시간표에서 원래 검색어가 있는 결과로 복귀하고 선택했던 결과의 초점을 복원하는 것이다. 브라우저의 뒤로 가기 자체가 고장 난 것으로 확대 해석하지 않는다.
- 일반 속도에서 즉시 클릭 3회·1초 대기 3회는 통과했다. 따라서 단순히 안정화 대기를 더한 테스트만으로 완료 처리하면 안 된다.
- 조사 지점: `app/components/SearchReturn.tsx:31`의 effect에서 document click capture를 등록한다. 초기 화면과 이벤트 등록 사이 경합은 코드상 가설이며 정확한 원인은 후속 수정 때 계측한다.
- 보완: 클릭 가능한 검색 링크의 초기 진입·hydration 경계에서 복귀 정보를 보장한다. 수정키/새 탭/외부 URL/다운로드, 세션 저장소 차단, KO/EN, 빠른 재탐색을 보존한다. 모든 링크를 무조건 클릭 차단하거나 임의 지연시키는 수정은 피한다.
- **완료 기준:** 같은 CPU 조건에서 즉시 클릭 후 복귀 값·링크·검색어·결과 초점이 유지되고 일반 속도·320/390/1440px에서도 회귀가 없다.
- 증거: `flows/early-return-cpu6-results.json`, `flows/early-return-cpu6-stable.json`, `flows/early-return-results.json`, `flows/recovery-results.json`.

### UX-02 영어 시간표 요약 라벨이 320px에서 겹침

- **P2 표시 결함, 재현 확인.** `/en/academic/timetable`, 320×1000, 빈 시간표, 기본 글꼴.
- `Unscheduled`와 `Conflicts`의 글자 Range가 **2.265625px 겹친다**. 390/1440px에서는 0px다. 전체 문서 가로 넘침 검사만으로 발견할 수 없는 내부 겹침이다.
- 원인 범위: `app/styles/m3/styles-academic-m3.css:397`의 빈 상태 모바일 4열 배치, `TimetableBuilderClient.tsx:1338`의 SummaryMetric.
- 보완: 매우 좁은 화면에서 2×2 배치 또는 라벨 최소 폭/줄바꿈을 적용한다. 통계 계산·공유·이미지 저장·강의 선택값은 유지한다.
- **완료 기준:** 320/360/390 KO/EN, 빈 상태와 강의 포함 상태에서 글자 겹침 0, 숫자·단위·버튼 잘림 0.
- 증거: `english-admin/metrics-320.png`, `english-admin/targeted-layout.json`.

### UX-03 지도 오류 안내가 정상 지도 크기의 빈 공간을 차지함

- **P2 오류 상태 UX 보완.** `/campus/map`, 390×1000, 현재 로컬 SDK 연결 실패 상태.
- 오류 카드 높이가 600px이며 y=278.39부터 878.39까지 차지한다. 짧은 안내에 비해 공간이 커서 이용 가능한 시설 정보가 늦게 나타난다.
- `app/campus/map/components/MapView.tsx:154`의 정상 지도 높이 규칙이 실패 상태에도 적용된다. 지도 연결 실패 원인은 이번 검사에서 확정하지 않았다.
- 도서관 검색 → 선택 → 중앙도서관 4개 층·17개 시설 표시와 해당 영역 이동은 성공했다. 대체 기능이 없는 결함은 아니다.
- 보완: 확정 실패 상태의 카드만 내용에 맞는 높이를 사용한다. 정상 지도·로딩 공간과 건물 검색은 유지한다.
- **완료 기준:** 실패 시 안내와 다음 행동이 좁은 화면에서 쉽게 보이고, 검색·선택·층 목록·재시도 및 정상 지도 복귀가 유지된다.
- 증거: `public-ui/ko-campus-map-390.png`, `public-ui/details.json`.

- **완료 기준:** 320/360/390/430px, 맑음·구름많음·비/눈·음수 기온 등 길이가 다른 문구에서 고립 음절·가로 넘침 없음.

### UX-05 글자 확대 스트레스에서 꿀팁 페이지 넘침

- **P3 접근성 조사·보완 후보.** `/en/campus/campus-tips`에서 CSS root font를 16px→32px로 변경한 실험이다. 실제 브라우저 200% zoom이나 OS 글자 크기와 동일한 검사가 아니다.
- 모의 정상 번역 조건에서 390px은 문서 폭 20px, 320px은 90px 초과했다. 503 원문 조건은 각각 16px이며 기본 글꼴에서는 넘침이 없다.
- `CampusTipsPageClient.tsx:171,193`의 rem 기반 음수 여백과 바깥 px 여백이 서로 달라져 320px 탭 래퍼가 left=-16/right=336이 된다. 카테고리 내부 가로 스크롤 자체는 정상이다.
- 보완: 스크롤 컨테이너를 부모 폭 안에 유지하고 실제 브라우저/기기의 확대에서 다시 확인한다. 모든 가로 넘침을 숨기는 처리로 탭을 잘라내지 않는다.
- **완료 기준:** 실제 확대에서 문서 전체 가로 스크롤 없이 탭 내부 이동·검색 버튼·입력·선택 상태를 사용할 수 있다.
- 증거: `english-admin/targeted-layout.json`, `text-200-390.png`, `text-200-320.png`.

## 사용자 관찰 후 판단할 항목

- **데스크톱 시간표:** 첫 강의 추가 버튼이 초기 y=1261px이며 필터/결과에 중첩 스크롤이 있다. 스크롤 후 y=624px에 노출되고 hit test는 통과했다. 발견성은 개선 가설이며 기능 차단으로 세지 않는다.
- **모바일 4안 비교:** fixture 전체 문서가 약 3,450px다. 네 번째 계획을 찾는 시간이 긴지 실제 사용자 조작으로 확인한 후 바로가기/현재 선택 표시를 검토한다. 최대 4안을 줄이지 않는다.
- **모바일 졸업요건:** 저장 fixture에서 교육과정까지 약 16,703px다. 필요한 영역으로 복귀하기 어려운지 확인한 후 선택적 접기를 검토한다. 문서가 길다는 이유만으로 조건·근거를 제거하지 않는다.

## 오탐과 검사 한계

일부 Select의 열림 애니메이션 중 크기 측정과 닫힘 직후 단언이 조기 실패했다. 화면 상태가 안정된 후 같은 조작이 통과했으며 서비스 코드는 바꾸지 않았다. 반면 UX-01은 느린 기기 조건에서 별도 반복 재현했으므로 일반 검사 통과로 덮지 않는다.

숨김 native Select의 1px 크기, `content-visibility`로 화면 밖 innerText가 빈 버튼, 정상 내부 가로 스크롤, 사각 격자/목록, 존재하지 않는 일정 방의 API 404는 결함에서 제외했다. 모든 모서리를 둥글게 바꾸는 수정은 필요하지 않다.

다음은 아직 확인하지 않았다.

- 실물 Android/iPhone, Safari/Firefox, OS 가상 키보드·IME·VoiceOver/TalkBack, 실제 브라우저 확대 및 전체 색 대비/axe 감사.
- 지도 정상 SDK 연결, 셔틀 공급자의 정상 실시간 응답. 기존 외부 장애 해결을 주장하지 않는다.
- 실제 문의 접수·메일/푸시·시간표 공유 생성·관리자 쓰기·Storage 업로드·Cloud TTL/할당량 설정.
- 기계 번역 의미와 긴 실제 학사 고유명 전수 품질. mock 문구는 구조·교체·실패 검사용이다.
- 최종 후보의 새 전체 타입·단위·빌드·감사·CI. 이번에는 제품 코드 변경이 없어 브라우저 QA와 문서 검증을 수행했다.
