# M3 화면 후속 수정과 저장 호환성 검증

2026-10-26 요청을 실제 서비스 코드에 반영했다. 외부 API·인증·저장 규칙을 변경하거나 UI 라이브러리를 추가하지 않았다. Framer Motion은 도입하지 않고 요청한 선택 표시만 CSS 200ms 전환으로 처리했다.

## 셔틀 표시 조사

기존 helper는 이미 노선마다 다음 출발 한 편을 계산했다. 홈의 `limit: 2`와 `departures[0]` 표시가 다른 노선을 숨기고 있었다. 정규 노선이 세 개이므로 추가 선택을 요구하는 즐겨찾기보다 세 노선을 기본 노출하는 구성을 적용했다. 운행 종료와 비운행을 혼동하지 않도록 다음 편이 없는 경우에는 사실 그대로 표시한다.

[M3 Lists](https://m3.material.io/components/lists/overview)의 항목 이름·지원 문구·우측 정보 구조를 사용했다. [TfL 버스 안내](https://tfl.gov.uk/modes/buses/)의 노선·정류장별 조회와 즐겨찾기는 정보의 기준을 명확히 하는 참고 사례이며, 새 즐겨찾기 기능은 추가하지 않았다. 실시간 위치 원본의 기존 오류와 이 정규 시간표 요약은 별개의 경로다. 실시간 위치 조회 로직은 이전 지시대로 유지했다.

## 저장 계약

| 기능 | 확인한 계약 |
| --- | --- |
| 졸업요건 | `syu-campus-graduation-self-check-v2`, raw JSON·export v2·`#graduation-progress=`, 공유 해시가 로컬보다 우선하는 기존 복원 |
| 시간표 | `syu-campus-timetable-draft-v1`, schema v2·구형 v1 복원, 30일 TTL, 최대 4개·활성안·선택 과목 |
| 시간표 공유 | 기존 `?share=`, 소유 토큰 키, 공유 조회 중 로컬 초안 보존·학기 불일치 확인 |
| Meet | 기존 owner/participant 키와 raw 토큰, 닉네임 정규화, 방 90일·응답 24시간 정책 |

관련 persistence·규칙 helper 7개의 내용은 이전 preview 지문과 일치하고, 기준 커밋 `e39cbb`의 storage 호출과 키 생성도 같았다. 새 격리 브라우저에서 이전 형식의 시간표·졸업요건·Meet 데이터 복원 5개 시나리오를 확인했다. 동일 origin에서 기존 저장을 읽는 계약을 보존했다는 의미이며, `127.0.0.1:4179`, `127.0.0.1:4180`, 운영 도메인은 origin이 달라 저장값을 자동 공유하지 않는다. preview의 가짜 서버 공유·일정 데이터는 실제 서버 데이터로 자동 이전되지 않는다.

저장 복원 브라우저 검증은 도구 표준 출력으로 기록했으며 별도 JSON·스크린샷 파일은 저장하지 않았다. 도서관 원본 매핑은 `lib/library.test.ts`와 `app/campus/library/page.test.tsx`의 회귀 테스트에도 포함된다.

## 검증

- 관련 테스트 13개 파일·105개 통과. 새 검색 초안/제출 분리, 같은 페이지 바로가기 닫기, 원본 URL 복귀, 날씨 상태·캐시·hydration, 셔틀 예외, 도서관 매핑 포함.
- 전체 ESLint·TypeScript·i18n 및 최적화 빌드 통과.
- 390/1440px 식당·버스 전환: 실제 중간 이동 프레임과 최종 156px 이동, 회색 트랙·흰색 표시, 버튼 48px, 가로 넘침·실행 오류 없음. 움직임 줄이기에서는 0초.
- 입력 중 공지/공모전 검색 API 요청 0회, 제출 후 검색 URL 이동, 동일 페이지 빠른 링크의 대화상자 닫기 확인.
- Header 네 방향 전환에서 같은 indicator 유지, 최종 위치 오차 0px, 메뉴 아이콘·48px 목표, 899/900px 양방향 초점 이전, JS 없는 초기 표시 확인.
- 한국어/영어 × 390/1440px 홈: 실행·hydration 오류 0, 날씨 요청 각각 1회, 날짜와 세 노선 표시 확인. 먼저 발견한 날씨 SSR/cache 불일치는 서버와 첫 hydration 출력을 일치시켜 수정하고 회귀 테스트를 추가했다.
- 도서관 390/1440px: 채움실 0, 좌석 버튼 7개, 마지막 1층 집중실의 `roomNo=13` 유지. 운영 쓰기 요청과 사용자 저장값 접근 없이 검증했다.
- 최종 최적화 빌드를 4180에 실행해 390/1440px 선택 전환·입력 중 API 0회·제출 검색·같은 페이지 바로가기 닫기를 재검증했다. 실제 날짜는 `2026년 10월 26일 월요일`, 날씨 문장은 `현재 캠퍼스 날씨는 17°C에 흐림입니다.`, 셔틀 3행이었다. 브라우저 실행·hydration 오류와 가로 넘침은 없었다.

증거는 Git에서 제외되는 `output/playwright/m3-followup-20261026/` 및 `output/playwright/m3-followup/`에 있다. 운영 배포·실제 기기·전체 스크린리더 검증으로 일반화하지 않는다.
