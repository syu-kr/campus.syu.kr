# UI 재사용과 디자인 기준

Material 3의 역할·상태와 기존 기능 계약을 함께 유지한다. 시안의 데이터와 페이지 로더를 복사하지 않고 실제 Next.js 경로와 API, 서버 렌더링 및 메타데이터를 사용한다.

## 현재 자산과 정리한 문제

`app/components`의 `Button`, `Card`, `Modal`, `Icon`, `Container`, `Badge`를 재사용한다. `app/styles/m3/foundation.css`의 역할 토큰과 `tailwind.config.js`의 대응 색상을 사용한다. 일반 버튼은 full, 입력은 12px, 카드는 20px, 패널은 24px, 대화상자는 28px 모서리를 적용한다. 달력·시간 선택·시간표 격자는 사각 구조를 유지한다.

일반 액션은 공통 버튼을 사용하고, 탐색은 직접 이동하는 헤더 링크·hover 및 키보드 하위 메뉴·반응형 하단 탐색으로 제공한다. 문구·접근 가능한 이름은 [다국어 정책](./I18N_POLICY.md)을 따른다. 성능의 측정 조건은 [성능 가이드](../PERFORMANCE.md), 미해결 운영·기기 확인은 [유지보수 경계](MAINTENANCE.md)를 따른다.

사용자 안내는 현재 상황과 다음 행동을 설명한다. API·SDK·JSON 해석 오류를 학생 화면에 직접 표시하지 않으며, 알 수 없는 서버 오류를 입력 오류로 분류하지 않는다. 조회 실패와 정상적인 빈 결과를 구분하고, 준비·만료·권한 차단 같은 원인은 확인된 경우에만 단정한다. 제출 응답을 받지 못한 경우에는 성공 여부를 확정하지 않고 입력값을 보존한다. 재시도·직접 복사·파일 내보내기 등 실제 제공되는 복구 수단을 안내한다. 개인정보 처리 고지와 공식 출처·저장 불가·알레르기 안내는 유지한다. 접수 여부가 불확실하면 중복 제출 가능성도 안내하고 정상 빈 목록·입력 오류·서버 장애를 서로 구분한다.

## 일반 액션은 Button 사용

정의는 `app/components/Button.tsx`, 기본 스타일은 `app/globals.css`의 `.ui-button`, M3 역할·상태 토큰은 `app/styles/m3/foundation.css`에 둔다. M3 범위의 역할 값이 최종 기준이며 화면마다 같은 값을 다시 덮어쓰지 않는다.

| 종류 | 용도 | 기본 표현 |
| --- | --- | --- |
| `primary` | 저장·전송 등 화면의 주요 동작 | 파란 배경, 흰 글자 |
| `secondary` | 취소·재시도·보조 동작 | 흰 배경, 회색 테두리 |
| `ghost` | 닫기·상위페이지 이동 등 가벼운 동작 | 투명 배경, 마우스를 올리면 배경 표시 |
| `danger` | 삭제 등 주의가 필요한 확정 동작 | 빨간 배경, 흰 글자 |

- 일반 액션은 최소 높이 **48px**, 모서리 **full**을 사용한다. 아이콘 전용 버튼은 폭도 48px 이상으로 두고 접근 가능한 이름을 제공한다. 달력·시간표·Meet 슬롯 등 정상적인 밀집 격자는 별도 역할을 유지한다.
- hover·pressed에는 공통 상태 레이어로 반응한다. 키보드 `focus-visible`에는 **3px** 포커스 링을 즉시 표시한다. 포인터 클릭의 운영체제 테두리와 사용자 정의 키보드 초점을 구분한다.
- 실행할 수 없는 버튼은 네이티브 `disabled`를 사용한다. 흐린 표시와 비활성 커서를 적용하며 클릭과 제출을 막는다. `aria-disabled`만으로 링크 실행이 차단되는 것은 아니므로, 이용 불가능한 이동은 링크 대신 비활성 텍스트로 표시하거나 별도로 실행을 막아야 한다.
- `prefers-reduced-motion: reduce`에서는 전환과 눌림 이동을 제거한다.
- `className`은 `mt-2`, `w-full`, `shrink-0` 같은 배치 조정에 사용한다. 일반 액션의 색·높이·모서리·상태 효과를 화면마다 다시 정의하지 않는다.

```tsx
import Link from "next/link";
import { Button, buttonStyles } from "@/app/components/Button";

<Button variant="secondary" onClick={retry}>다시 시도</Button>
<Button type="submit" disabled={pending}>저장</Button>
<Link href="/campus" className={buttonStyles("ghost")}>캠퍼스</Link>
```

`Button`의 기본 `type`은 `button`이다. 폼 전송은 **`type="submit"`을 명시**한다. 페이지 이동은 `Link` 또는 `<a>`의 의미를 유지하고 `buttonStyles`로 외형만 공유한다. `Button`을 `Link` 안에 넣거나 이동을 일반 버튼의 클릭 이벤트로 대체하지 않는다.

룸메이트 화면의 기존 `primaryClass`·`secondaryClass`는 `RoommateShared.tsx`에서 `buttonStyles`를 참조한다. 네이티브 `<button>`과 링크가 이 스타일을 사용하는 경우도 공통 디자인을 재사용하고 있다.

## 탐색과 검색

헤더 로고 왼쪽의 상위 이동 화살표는 표시하지 않는다. 상단 학사·캠퍼스·더보기 링크를 누르면 해당 메뉴 페이지로 바로 이동하고, hover·focus·ArrowDown으로 하위 메뉴를 연다. Escape로 닫고 시작 링크에 초점을 복귀한다. 900px 미만에서는 하단 탐색, 600px 미만에서는 아이콘 위·문구 아래 구성을 사용한다. 본문의 목록·취소·메뉴 링크와 브라우저 기록은 각 기능의 기존 복귀 흐름을 유지한다.

돋보기는 처음 누를 때만 검색 대화상자를 마운트한다. 검색어는 홈의 기존 search URL과 실제 통합 검색 API를 사용하고, 서비스 바로가기와 데이터 결과를 함께 제공한다. 같은 출처의 검색 결과로 이동한 경우 검색어·스크롤·결과 링크 초점을 복구한다. sessionStorage 접근이 차단돼도 화면은 렌더링된다. 독립 홈 검색창의 서버 HTML과 hydration 전 입력 보존은 유지한다.

푸터의 문의 항목은 텍스트 형태의 네이티브 버튼으로 유지하고 문의 대화상자는 처음 열 때 지연 로딩한다. 외부 이동·전화·메일은 원래 링크 의미와 아이콘을 유지한다.

## 목적에 따라 유지하는 컨트롤과 남은 범위

선택 칩·탭, 달력 날짜, 시간표 격자와 과목 선택, 지도 시설 선택, 본문의 참고 링크는 서로 다른 목적과 상태가 있다. 일반 액션 버튼으로 일괄 바꾸지 않는다. 선택 상태는 `aria-pressed`·`aria-current` 등 해당 의미로 표현하고, 본문 링크의 밑줄은 문서 탐색 표현으로 유지할 수 있다.

일반 액션은 Button 또는 buttonStyles, 아이콘 전용 액션은 m3-icon-button을 사용한다. 일반 목표 크기는 48px이며, 정상적인 달력·시간표·Meet 슬롯은 밀집 격자 예외이다. 기본·hover·키보드 focus-visible·pressed·disabled·오류 상태를 역할별로 확인한다. 포인터 클릭의 운영체제 테두리는 없애되 사용자 정의 키보드 초점은 3px로 유지한다.

문의 유형·시간표 학과·국가/언어·페이지 선택·홈 대중교통 정류장은 승인된 shadcn Base UI 기반 `M3Select`를 사용한다. 언어·페이지·홈 정류장 선택은 공통 tonal pill, 입력 폼은 field 표현을 사용한다. 기존 선택지와 이벤트·검증을 보존하며, 대화상자 안의 팝업은 기존 focus boundary 내부에 포털한다. 나머지는 네이티브 select의 레이블·값·키보드·fallback을 유지한다. 선택 표시·팝업·상태 전환은 공통 CSS 140~200ms와 reduced motion을 사용하며 Framer Motion은 도입하지 않는다. 시안 fixture를 서비스 런타임에 포함하지 않는다.

서비스 공지는 날짜·제목/요약·이동 아이콘을 정렬한 단일 목록으로 표시하며 최신순 10개씩 서버에서 준비한다. 공통 `PaginationControls`와 `?page=` 링크로 이동하고, 상세의 목록 복귀 링크는 검증한 `listPage`를 사용한다. 상세 canonical에는 복귀 parameter를 넣지 않는다. 공지 frontmatter의 `lang: en`은 영어 원문의 제목·본문·OG에 적용하며 선언이 없으면 기존 한국어를 사용한다.

홈의 PWA 안내는 `앱 설치` 네이티브 버튼을 사용한다. 저장한 브라우저 설치 이벤트가 있으면 클릭 안에서 설치 창을 열고, 이벤트는 한 번만 사용한다. 취소 후에는 새 설치 이벤트를 기다리며, 사용할 이벤트가 없거나 호출이 실패하면 화면에 추가하는 방법을 기존 `Modal`로 안내한다. 안내 모달은 열 때 지연 로딩하며 키보드 닫기·초점 복귀를 유지한다. 설치 승인·완료 또는 앱의 standalone 실행 상태에서는 카드를 숨긴다.

## 기능·저장·복귀 계약

- 학교 공지는 원문 링크로 이동하고 AI 요약은 목록과 함께 참고용으로 제공한다. 원문·알레르기·개인정보·졸업 판정 등 필요한 고지는 디자인 정리로 제거하지 않는다.
- 시간표는 원본 학과·학년·이수구분·요일·교시 등 모든 검색 조건과 선택값, 최대 4개 비교안·충돌 검증·초안·공유를 보존한다. 인쇄·이미지 내보내기에는 일요일·시간 미정 강의를 포함한 모든 선택 강의를 담는다. 표시하지 않는 무거운 격자를 초기 마운트하지 않는다.
- 졸업요건은 기존 입학년도·소속·입학유형·전공 형태의 종속 선택·진행 계산을 보존한다. 변경·초기화 취소와 Escape에서는 기존 진도를 유지하고 시작 컨트롤로 초점을 돌린다. 개인별 공식 졸업 판정 API로 설명하지 않는다.
- `syu-campus-timetable-draft-v1`, `syu-campus-graduation-self-check-v2`와 기존 Meet token의 키·형식·TTL, URL query/hash 복원을 유지한다. 저장 형식 변경을 UI 정비에 묶지 않으며 다른 origin의 저장값이 자동 공유된다고 가정하지 않는다.
- 모달의 조회 실패와 저장 실패는 따로 안내한다. 응답을 확인하지 못한 양식은 입력을 지우지 않으며 실제 `success`가 확인됐을 때만 성공·초기화를 표시한다. 복사 실패 시 직접 복사, 저장 불가 시 기존 파일 내보내기 등 손실을 줄이는 수단을 유지한다.
- 셔틀은 특별 기간을 별도 시간표로 선택하고 기본 시간표로 돌아갈 수 있어야 한다. 날짜·노선별 적용 조건과 참고 탭을 현재 운행 정보에 혼합하지 않는다. 지도 오류에서는 건물 검색·시설 목록을 제공하고 쿠키·외부 콘텐츠 안내를 원인 단정으로 쓰지 않는다.
- 공개 팝업의 초기/완료 후 닫기·오늘 숨김·다른 dialog 양보·초점 복귀와 숨긴 이미지 요청 0건을 유지한다. 초기 셸 준비는 전체 문서·Suspense·hydration 완료와 구분한다. 게시·저장 정책은 [관리자 가이드](ADMIN_CONTENT.md), 번역 범위·오류 복구는 [번역 가이드](CONTENT_TRANSLATION.md)를 따른다.

## 변경 시 검증

- `npm run type-check`와 변경한 공통 컴포넌트·화면의 관련 테스트를 실행한다. 전체 검사 명령과 구성은 [개발 가이드](../DEVELOPMENT.md)를 따른다.
- 320·390·768·1440px에서 긴 한국어·영어 문구, 검색 입력과 초기화, 로딩·빈 상태·오류 상태를 확인한다. 의도하지 않은 가로 스크롤과 화면 밖으로 밀리는 버튼이 없어야 한다.
- 키보드 순서와 포커스 표시, 모달 열기·닫기·포커스 복귀·배경 스크롤, 버튼의 접근 가능한 이름과 비활성 상태를 점검한다. 모달 제목만 표시되고 실제 조작이 불가능한 상태도 실패로 취급한다.
- 시간표의 초안·선택 상태를 유지하며 무거운 모달의 첫 마운트를 열 때까지 늦춘다. 다시 열 때 보존할 상태가 있으면 기존 `keepMounted` 동작을 유지한다. 공통 폰트와 시간표 모바일 폰트의 문자 범위·fallback·이미지 저장은 [성능 가이드](../PERFORMANCE.md)에 따라 확인한다.

검증 결과에는 커밋·화면·언어·viewport·실제 실행한 명령을 기록한다. 로컬 브라우저, 실제 기기, 외부 API·인증 연동, 운영 배포 검증은 각각 구분한다. 과거의 테스트 수·취약점 수나 `main` 검사 성공을 현재 상태의 보증으로 재사용하지 않는다.
