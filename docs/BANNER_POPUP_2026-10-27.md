# 점검 공지 팝업 전환

사용자가 제시한 쇼핑몰 팝업 예시의 표시 방식을 반영했다. 화면 중앙에 이미지·안내문·하단 두 버튼을 놓고 배경을 어둡게 한다. 기존 M3 토큰과 `Modal`을 재사용했으며 새 의존성은 없다. 기존 홈 카드·상단 안내 선택지는 유지하고 관리자 노출 위치에 **팝업 공지**를 추가했다.

## 표시·닫기 계약

- 이미지 전체를 `contain`으로 표시하고 작은 화면에서는 본문을 스크롤한다. 하단 버튼은 스크롤 중에도 접근할 수 있다.
- **닫기**, Esc, 배경 클릭은 현재 탭의 `sessionStorage`에 저장한다. 같은 게시본은 새로고침·내부 이동에도 다시 열지 않는다.
- **오늘 그만 보기**는 한국 시간 다음 자정까지 `localStorage`에 저장한다. 새 게시 revision은 다시 표시한다. 저장이 막혀도 현재 화면에서 닫을 수 있다.
- 저장 상태를 확인한 뒤 열어 이미 숨긴 팝업의 순간 노출·초점 이동을 방지한다. 여러 공지는 우선순위대로 한 번에 하나씩 표시한다.
- 팝업은 서버에서도 닫기 허용을 고정한다. 관리자는 방문자가 닫을 수 없는 팝업을 게시할 수 없다. 기존 카드/상단형의 닫기 설정은 유지한다.
- 공통 모달의 초점 제한·Esc·스크롤 잠금·초점 복구를 재사용한다. 본문 언어와 제목 언어를 표시하고, English에서는 팝업 안에서도 Google 표기와 번역 실패·재시도를 제공한다.
- 관리자·룸메이트·개별 일정 방에서는 조회·표시하지 않는다. SPA 이동 시 현재 경로를 다시 확인하며 비공개 페이지에서 공개 페이지로 이동해도 필요한 공지를 조회한다.
- 시작/종료·광고 표시·외부 링크·권한·revision 충돌·게시 중단 정책은 기존 계약을 따른다. JS 비활성 환경에서는 팝업으로 서비스 이용을 막지 않는다.

## 이번 점검 공지

기존 승인 공지 한 개만 `site-top`에서 `popup`으로 변경했고 게시 revision은 2다. 콘텐츠 쓰기 1회, 이미지 업로드 0회, 다른 콘텐츠 변경 0회이며 읽기 검증까지 완료했다. 첨부 사진·제목·안내 문구·우선순위는 같다.

> 2026.10.27(화) 16:00–17:00(KST) 서비스 업데이트와 데이터 이전을 진행합니다. 일부 기능이 잠시 원활하지 않을 수 있습니다.

17시 자동 종료는 없다. 실제 완료 확인 후 관리자에서 게시 중단한다. 팝업을 닫는 방문자의 설정과 관리자의 전체 게시 중단은 별개다. 이 변경은 앱 코드 배포가 필요하며 Git 병합만으로 기존 운영 화면이 바뀌지 않는다.

## 검증

- Node 24.22.1, 관련 8파일 **89테스트 통과**: 관리자 선택·정규화·API 위치 허용·공개 우선순위·기존 모달·포커스 복구·탭 닫기·KST 자정·revision·여러 공지·민감 경로·Storage 차단을 확인했다.
- 대상 ESLint, 전체 TypeScript, i18n·미사용 검사 통과.
- 로컬 프로덕션 빌드 `f-LPK3VDtMmLwI0JwSRPg` 성공. `PUBLIC_DATA_BACKEND=firebase`, `SERVICE_NOTICES_SOURCE=hybrid`.
- 이 빌드의 브라우저 JS/CSS/JSON 80파일·2,655,671B에서 선택 서버 비밀값 표현 10개와 개인 경로 일치 0. 서버 trace 81개에 로컬 QA·환경·무관한 Markdown 0, 필요한 공지 37개·졸업 JSON 5개 포함을 확인했다. 전체 비밀정보 감사를 의미하지 않는다.
- Playwright Chromium에서 KO/EN × 320/390/1440px **6화면 통과**. 패널의 화면 내 배치·넘침 0·이미지 naturalWidth 576/contain·48px 이상 버튼·초기 초점·Tab 왕복·Esc·배경 클릭·스크롤 복구·닫은 뒤 reload를 확인했다. 한국어 390/1440px 캡처를 눈으로도 확인했다. 이전 상단형 148화면 결과를 새 팝업의 실행 결과로 계산하지 않았다.
- KST 다음 자정 저장, 같은 revision 숨김/새 revision 재노출, 만료 숨김 값, Storage 차단, 관리자→홈 SPA·룸메이트 비노출·일반 닫기 유지, 320px EN 루트 글꼴 200%의 번역 503→재시도 성공을 확인했다. 브라우저 예외 0, Google 실제 호출·업무 쓰기 0이며 영어 성공 응답은 fixture다. 루트 글꼴 확대는 OS/브라우저 전체 확대를 대신하지 않는다.
- 최초 공개 API 조회는 기존 1초 예산 안에 목록을 읽지 못해 빈 결과였고 다음 정상 GET에서 revision 2를 확인했다. 이것을 실제 팝업/제공자 실패와 섞지 않았다. 후속 하네스의 hydration 대기·숨겨진 nav 선택 오류도 원본을 보존하고 대기 조건/visible 선택자로 고친 뒤 최종 `complete:true`, exit 0을 확인했다. 로컬 원본·캡처는 Git 제외 `output/playwright/firebase-goal/popup-20261027/`에 있다. EN 확대 오류 캡처의 이미지 로딩 placeholder를 이미지 완료 증거로 사용하지 않았다.
- 최종 원격 CI는 [PR #271의 최신 head Checks](https://github.com/syu-kr/campus.syu.kr/pull/271/checks)에서 확인한다.

실제 병합·배포·공개 자료 활성화·Actions 실행·알림 발송은 수행하지 않았다. 실기기 Safari·스크린리더와 Production 도메인의 최종 표시는 별도 확인한다.
